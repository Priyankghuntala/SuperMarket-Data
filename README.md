# Supermarket Sales Analytics Dashboard (Power BI)

This project presents an interactive Power BI dashboard designed to analyze supermarket sales data and generate actionable business insights.

The dashboard enables business stakeholders to explore sales performance, customer purchasing patterns, and product profitability through dynamic visualizations and KPIs.

## Key Features

• Interactive dashboard built using Power BI  
• Data cleaning and transformation using Power Query  
• Advanced measures created with DAX  
• Dynamic filtering and slicing for detailed analysis  
• Business KPI tracking for sales performance  

## Insights Generated

• Sales performance by city and product category  
• Revenue and profit analysis across different branches  
• Customer purchasing trends and behavior patterns  
• Identification of top-performing products  
• Sales distribution and operational performance metrics

## Business Value

This dashboard helps decision-makers quickly identify revenue drivers, understand customer behavior, and optimize product strategies using data-driven insights.
